# imaging 模块

`imaging` 保存跨工作流复用的基础图像处理函数。它只处理通用像素操作，不关心某个具体子流程的业务含义。

## 包含文件

- `common.py`：RGBA 加载保存、RGB 距离、像素混合、8-bit clamp、洋红色键控、边界连通近似洋红背景清理、水平/垂直平铺修复、横向色彩调和、网格切片和 zip 打包。

## 修改规则

- 被两个以上 workflow 复用的像素操作放到这里。
- 保持函数输入输出简单明确，优先使用路径、Pillow image 对象和基础 Python 类型。
- 调整色键逻辑时先用 `.codex-tdd-tests/` 覆盖纯洋红、近似洋红背景和角色内部紫色细节，避免扩大阈值误伤素材。
- 如果某个算法只对单一子流程有意义，放到对应 `workflows/*.py`，不要提前抽到这里。
